# Zod MVU世界书协议

当前Zod方案使用四个核心条目。条目名称可保留用户现有命名，但用途与协议必须完整。

## `[initvar]变量初始化勿开`

- 保持禁用；MVU按名称读取它完成新聊天初始化。
- 正文是Schema输入形状的YAML初始值，不写Zod代码，不使用旧版 `[初始值, 更新说明]` 成对数组。
- 必须能被当前Schema成功解析。

## `变量列表`

- 常量条目，通常置于深度0、system角色。
- 把当前消息的 `stat_data` 提供给模型。
- 正文使用模板中的固定宏，不在此重复解释每个变量的规则。

## `[mvu_update]变量更新规则`

- 按Schema和用户要求描述变量语义、类型、范围及更新条件。
- 固定字段的同类规则可以合并；动态字典在 `type` 中写索引签名。
- 字符串类型通常不必重复标注类型。
- 不列出 `_` 开头的只读派生字段。
- 规则应短而明确，不把界面HTML或派生显示数据放进世界书。

## `[mvu_update]变量输出格式`

- 使用当前Zod JSON Patch协议，不改回旧版三参数 `_.set`。
- 支持 `replace`、`delta`、`insert`、`remove`、`move`。
- 更新路径使用JSON Pointer形式。

模板位于 `templates/zod/worldbook/`。模板Frontmatter只是安全起点；写入前仍需查看当前世界书已有条目的位置、顺序与命名，避免重复或无意义重排。

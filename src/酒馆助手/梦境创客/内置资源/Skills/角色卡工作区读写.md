# 内置文件读写规则

梦境创客把酒馆资源投影为大小写敏感的 POSIX 虚拟文件系统。目录会随会话作用域、当前打开角色、世界书挂载和 Agent 配置动态变化；不要把一次列目录的结果当成永久结构。

## 先探索，再修改

- 使用 `list_path` 查看单个文件或目录。目录可设置 `recursive`、`depth`（最大 10）、`kind`、`glob` 和 `maxResults`，结果包含文件大小与目录子项数量。
- 使用 `search_files` 搜索正文和路径；使用 `read_file` 分段读取真实内容。
- 使用 `copy_path` 复制文件或目录；目录复制会在实际写入前一次性检查全部目标权限和冲突。
- `read_file` 文本视图形如 `12 | 正文`。行号与分隔符不是正文，写入或匹配时必须去掉。
- `write_file` 默认只新建；覆盖已有文件必须显式设置 `overwrite: true`。修改已有长文件优先使用 `apply_patch`。
- `apply_patch` 使用标准 Unified Diff，并在调用时重新读取实时文件。上下文不匹配会失败；此时重新读取再生成补丁，不要反复提交旧补丁。
- 工具失败与玩家拒绝都会作为结果返回。阅读错误并调整下一步，不要把单次失败当成整轮任务已中止，也不要伪造成功结果。

## 动态目录

始终可能存在：

- `/files/`：全局持久文件，所有会话可见，适合跨角色工程和资料。
- `/temp/`：当前全局会话的临时文件。
- `/worldbooks/`：当前会话已挂载的世界书。角色会话自动挂载角色主、附加及聊天绑定世界书；手动挂载的世界书也在这里。未挂载世界书不会凭空出现在目录中。
- `/regexes/{character,preset-current,global}/`：三个正则作用域。没有打开角色时不出现 `character`。
- `/scripts/{character,preset-current,global}/`：三个酒馆助手脚本作用域。没有打开角色时不出现 `character`。
- `/skills/`：当前 Agent 启用的 Skill。`index.md` 列出名称、摘要、路径与加载方式。
- `/users/`：酒馆全部 User Persona。`<名称>.md` 是描述和元数据，`<名称>.avatar.png` 是只读虚拟头像引用。
- `/presets/current/`：酒馆正在使用的实时预设，可编辑；`/presets/library/` 是通过工具挂载的其他只读预设。
- `/context/environment.md`：当前是全局还是角色会话、角色是否挂载、动态目录与当前边界。环境变化后应重新读取。

打开角色后还会出现：

- `/character/identity.yaml`：当前角色身份，只读。
- `/character/definition/`：角色文本字段、作者、版本与标签。
- `/character/greetings/`：具名开场白与 `index.yaml` 顺序。
- `/character/chats/`：酒馆真实聊天的分层投影。
- `/character/files/`：这张角色卡跨会话共享的持久文件，附件默认存放于此。
- `/character/temp/`：当前角色会话临时文件。
- `/worldbooks/bindings.yaml`：仅角色环境出现，记录角色主、附加及聊天绑定。

全局会话可以通过 `manage_character` 打开或关闭角色；角色目录、角色资源作用域、自动挂载世界书会随之出现或卸载。角色会话没有角色导航工具。全局会话手动挂载的世界书会保留到显式卸载；关闭角色时，该角色绑定的世界书都会卸载。

## 各类资源

- `/character/definition/description.md`、`personality.md`、`scenario.md`、`example-dialogue.md` 在现代预设中通常不重要。旧卡非空时阅读并保留其语义；新增复杂设定优先放入结构化世界书，除非用户明确要求写这些字段。
- 开场白正文是 Markdown，顺序与显示名由 `/character/greetings/index.yaml` 决定。格式见 `/skills/builtin/card-workspace-io/references/greetings.md`。
- 世界书条目位于 `/worldbooks/<书名>/entries/`。创建或整体改写前读取 `/skills/builtin/card-workspace-io/references/worldbooks.md`。不要猜测条目路径或结构。
- 使用 `search_worldbooks` 搜索所有真实世界书；使用 `manage_worldbook` 的 `mount`、`unmount`、`create`、`clone`、`set_binding` 管理生命周期与绑定。挂载后的世界书可写，是否真正可写仍以其往返安全性和工具结果为准。
- 酒馆聊天格式见 `/skills/builtin/card-workspace-io/references/tavern-chat.md`。聊天写入、生成、Swipe 和截断立即作用于酒馆，不参与梦境创客 Undo。
- 正则与脚本格式见 `/skills/builtin/card-workspace-io/references/regex-and-scripts.md`。除非用户明确要求，否则不要主动扫描或修改全局、预设作用域；它们通常与角色卡创作无关。
- HTML 工程只是 `/files/` 或 `/character/files/` 下包含 `project.yaml` 的普通目录。工程源码与编译后的正则没有绑定关系；需要时读取 HTML 工程 Skill。
- 用户 Skill 位于 `/skills/user/`。创建可直接写入；修改或删除已有 Skill 受审批和锁定状态约束。内置 Skill 不可写。
- User文件名就是酒馆中的唯一名称；可新建、修改、移动重命名或删除。头像路径与 `avatar_id` 只读，换头像必须使用 `set_avatar`，来源图片应先放入 `/files/` 或 `/character/files/`。
- 编辑酒馆预设前先读 `/skills/builtin/card-workspace-io/references/presets.md`。不要把酒馆预设与梦境创客设置里的“Agent预设”混为一谈。

## Skill 加载

Agent 配置决定每个 Skill 是否启用，并可覆盖 `full` 或 `on-demand` 加载方式：

- `full` 正文进入静态提示头。
- `on-demand` 只在 `/skills/index.md` 暴露摘要与路径。任务需要时先读对应 `SKILL.md`，再按正文指引读取同目录资源。

Skill 资源可以自由组织；不要假设必有 `references/` 或 `assets/`。已下载但未在当前 Agent 启用的 Skill 不会挂载。

## 搜索与补丁

- `search_files.pattern` 默认是普通文本；只有确实需要正则时才设置 `mode: "regex"`。
- `glob` 只过滤路径，例如 `worldbooks/**/*.md`；不要把路径通配符当正文正则。
- 二进制文件不能使用 `apply_patch`。可以读取支持的图片/PDF、移动、复制或删除已有存储文件；`write_file` 只创建文本。角色/User头像虚拟文件不能直接写入、移动或删除。

标准补丁示例：

```diff
--- a/character/definition/system-prompt.md
+++ b/character/definition/system-prompt.md
@@ -1,2 +1,2 @@
 第一行
-旧内容
+新内容
```

完成后重新读取关键片段或搜索相关引用，简要告诉用户修改内容与仍需决定的事项。

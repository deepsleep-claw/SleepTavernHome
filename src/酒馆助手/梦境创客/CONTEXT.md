# 梦境创客

梦境创客是在酒馆内辅助角色卡创作的 Agent。这里统一描述其连接渠道、模型配置与会话选择所使用的领域语言。

## 语言

**Provider（渠道）**：
一套可复用的模型服务连接，保存接口格式、Base URL、API Key和渠道级高级请求配置，可包含多个模型。
_避免使用_：API Profile、模型配置

**Model（模型配置）**：
Provider 下可独立启用或禁用的模型项，保存模型ID、兼容模式、能力、生成参数和模型级高级请求配置；同一模型ID可以拥有多套本地配置。
_避免使用_：Provider、API Profile

**高级请求配置**：
Provider和Model均可定义的自定义请求标头与附加参数；请求时合并两层配置，同名项以Model为准。
_避免使用_：模型参数、兼容模式

**本地模型模板**：
随脚本提供的模型能力与参数建议，可声明模型ID的精确、前缀、后缀或部分匹配规则；只在添加模型或用户明确应用时复制到Model，不是运行时配置引用。
_避免使用_：模型Profile、Provider模板

**云端模型模板**：
用户主动拉取并选择的模型能力与参数建议，只在明确应用时复制到Model。
_避免使用_：自动配置、远端Model

**会话模型选择**：
会话保存的Provider与Model引用；打开会话时若引用不存在或已禁用，则本次显示为未选择，不自动切换或改写原会话记录。
_避免使用_：全局活动Profile、不可用模型

# 基米工具

将模型返回的工具参数收集到聊天正文，使用酒馆当前的聊天补全接口。

## 使用

1. 在酒馆助手的脚本库中导入 `dist/酒馆助手/基米工具/基米工具.json`。
2. 在输入框旁的「扩展工具」菜单中点击「基米工具」，打开「启用基米工具」；也可使用脚本按钮「基米工具设置」。
3. 配置模型名称关键词、正文工具和提示词，点击「保存设置」。

设置存放在此脚本的 `tool_output_bridge` 变量中。`enabled` 是开关，`modelNameIncludes`
是模型名称关键词，其他字段保存工具定义、正文参数路径、提示词与注入位置。切换角色、聊天或聊天补全预设后继续使用这些配置；直接编辑脚本变量后，下一次请求会读取新值。

每个工具可以收集多个字符串参数。在「正文字段路径」中每行填写一个路径，如 `thinking` 和
`text`，内容按填写顺序连接到同一条消息。支持嵌套路径，如 `story.text`、`chapters[0].text` 和
`/story/text`。字段可为空字符串，字段之间使用正文分隔符。

提示词注入方式包括「不注入」「注入系统提示词」「注入User」「注入Assistant」「注入System」。「注入系统提示词」在请求开头新增系统消息；后三种方式按所选角色的现有消息计数并追加内容。深度
`0` 为第一条，`1` 为第二条，`-1` 为最后一条，`-2` 为倒数第二条。目标不存在时显示警告并继续发送请求。

提示词支持 `{{tool_names}}` 与 `{{tool_outputs}}`，会展开为启用工具的名称和全部正文字段。

响应按上游实际交付的节奏显示。流式请求完成后，浏览器控制台会输出「流式诊断」，包含参数事件次数和处理耗时。

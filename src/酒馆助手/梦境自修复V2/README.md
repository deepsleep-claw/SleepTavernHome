# 梦境自修复 V2

在角色回复结束后按选定模块生成格式补全和自检报告，追加到当前回复，再应用补丁。MVU 的消息处理在修复完成后继续执行。

## 使用

运行 `pnpm run build`，将 `dist/酒馆助手/梦境自修复V2/梦境自修复V2.json`
导入酒馆助手脚本库。点击“正文修复”打开操作面板。面板适配电脑和手机。

安装 V2 后停用旧版“格式补全”和“梦境自修复”脚本。报告展示使用 `dist/酒馆助手/梦境自修复正则UI/梦境自修复正则UI.json`；隐藏正则可将报告从后续主模型请求中移除。

“格式补全”和“内容修复”分别提供开关及提示词编辑器。组合预览展示当前任务尾部，最近一次实际请求展示酒馆宏展开后发送的完整文本。API 密钥保存在该脚本的变量配置中。

自动模式捕获本轮预设请求；手动模式可捕获当前预设。默认保留末尾 user 消息中 `</dream_dx_setting>`
及之前的内容，替换其后的任务。定位表达式支持 `/表达式/标志`，也支持字面文本。关闭尾部替换时将任务追加为新 user 消息。

配合“梦境自修复正则 UI”可在回复中折叠展示报告、重新应用补丁及还原补丁。V2 启用时统一接管自修复操作；格式补全入口也会打开 V2 面板。

## 补丁

普通补丁替换一个非空文本行，匹配时忽略首尾空白。可用完整段落或段首、段尾定位。同一补丁的多个匹配段落全部替换。

```text
FIND: 完整原文段落
REPLACE: 完整新段落

HEAD: 原文段首
TAIL: 原文段尾
REPLACE: 完整新段落
```

跨行块按起止文本定位，替换范围包含两个匹配文本。块标签独占一行，内部文本按原样写入。空替换内容表示删除。

```text
HEAD: "path": "/角色/体力",
TAIL: "value": 30
<REPLACE_BLOCK>
"path": "/角色/体力",
"value": 25
</REPLACE_BLOCK>
```

所有定位基于本轮原消息。检查报告属于审校记录。补丁重叠或首尾配对有歧义时记录错误，其他有效补丁继续执行。修复记录随楼层和候选回复保存，还原使用实际成功的替换记录。

## MVU

使用提供 `Mvu.getMessageUpdateStatus()` 和 `Mvu.reprocessMessage(message_id)` 的 MVU 版本。接口协议版本为 1。

将配套 MVU 仓库的 `artifact/bundle.js` 内容更新到已安装的 MVU 脚本中，保留该脚本的变量配置。

随正文输出模式检测成对的 `<UpdateVariable>`
标签。完整更新块可由内容补丁修正；缺失或残缺时，格式补全任务包含变量更新块。修复后重新解析命令，以此前有效楼层的变量为基准重算。

独立解析模式在正文修复后发起变量模型请求。手动关联更新会清理旧变量更新块、恢复此前楼层的变量基准，再请求 MVU。生成修复及 MVU 关联更新作用于当前最后一条角色回复。

切换聊天、修改目标回复或切换候选回复时，在途修复结果失效。停止或超时会取消对应的修复生成请求。

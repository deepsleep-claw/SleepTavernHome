# 梦境 RPG

在聊天中渲染冒险手札式行动面板，支持行内动作、分组选项、自定义行动与 D100 判定。主题可跟随酒馆或固定为暖纸亮色、墨蓝暗色。

## 导入

执行 `pnpm run build` 后，分别导入以下文件：

| 文件                                                 | 导入位置       |
| ---------------------------------------------------- | -------------- |
| `dist/酒馆助手/梦境RPG/梦境RPG.json`                 | 酒馆助手脚本库 |
| `dist/酒馆助手/梦境RPG前端/梦境RPG前端.json`         | 酒馆正则       |
| `dist/酒馆助手/梦境RPG行动美化/梦境RPG用户行动.json` | 酒馆正则       |
| `dist/酒馆助手/梦境RPG结果美化/梦境RPG判定结果.json` | 酒馆正则       |

前端的完整 HTML 同时输出为
`dist/酒馆助手/梦境RPG前端/index.html`。前端通过当前消息楼层读取选项目录，依赖已启用的梦境 RPG 脚本。在扩展设置中展开“梦境RPG”可调整配置；前端齿轮在界面内展开设置，两处共用脚本配置并同步更新。用户行动和 AI 结果通过 CSS 变量使用同一主题。

## 主持格式

```xml
<dream_after_format>
<dream_rpg>
这只旧箱子还扣着锁，要不要<opt id="inspect_lock" mode="secret" dc="60">查看锁孔</opt>？
<group id="guard_response" type="handle" mode="open">守卫转过身来了，你打算怎么应对？
<opt dc="80">假装整理行李</opt>
<opt mode="secret" dc="50">悄悄退回阴影</opt>
<opt mode="none">上前打个招呼</opt>
</group>
</dream_rpg>
</dream_after_format>
```

每轮行动 ID 使用英文字母、数字和下划线，且本轮内唯一。每组包含 2–4 个选项。子选项继承组的明暗类型，可单独覆盖类型；无需检定的选项省略
`dc`。

点击行动会写入消息输入框。同组再次选择替换该组草稿，其他内容保留。组内预设下标从 `0` 开始，自定义行动下标为
`-1`。点击时记录行动所属楼层，发送时按对应楼层的语境结算。

```xml
<rpg_ans id="guard_response" select="0">
假装整理行李
</rpg_ans>
```

发送或编辑用户楼层时，脚本补齐语境、明暗类型、成功率和骰点：

```xml
<rpg_ans mode="open" q="守卫转过身来了，你打算怎么应对？" dc="80" check="42">假装整理行李</rpg_ans>
```

自定义或经过改写的行动使用 `dc="unset"`。无需检定的行动使用 `mode="none" dc="none"`。无需检定的选项组中的自定义行动以
`open` 提交，交由主持人确定是否需要判定。无法定位的草稿保持原文。

带有 `check`
的标签保持原文；缺少骰点时，脚本根据配置复用同一轮中相同语境、明暗类型、难度与行动的骰点，或生成新的点数。缓存与目录保存在消息楼层变量
`dream_rpg` 中，聊天和消息页之间分别保存。编辑、切换消息页和切换聊天均会刷新目录。

主持人可在正文开头逐项输出结果标签，标签正文填写本次实际行动或判定事项。预设行动沿用输入难度；`unset`
行动先确定数值难度，再输出结果：

```xml
<rpg_check mode="open" dc="80" check="42">假装整理行李</rpg_check>
<rpg_check mode="secret" dc="60" check="24">查看锁孔</rpg_check>
```

结果使用两行注解：第一行显示行动或判定事项，第二行显示 D100 分级与数值。`q` 属性可携带补充语境；自闭合结果标签以 `q`
作为显示内容。

两条显示正则匹配标签内的行动文字，提供 HTML/CSS 骨架。脚本读取对应消息补充数值与分级；流式更新时保留正文和行动节点，仅更新变化的判定细节。正则只改变消息显示，模型收到的文本仍为原始标签。

用户回答先显示对应问题或语境，再显示行动与难度、成功率，行动文字继承酒馆字体。成功率 5–20%、21–40%、41–60%、61–80%、81–95% 分别对应非常困难、困难、普通、简单、非常简单；难度徽标依次使用暗红、红色、黄绿、常青绿、鲜绿。行旅面板采用相同分级与颜色。`dc="unset"` 的自定义或改写行动显示 `[命运未定]`，主持人确定数值难度后，在 AI 结果中展示正式判定。AI 结果的六档判定分别使用鲜绿、常青绿、黄绿、金黄、红色与暗红色，文字、侧线与渐变背景随等级变化。亮暗主题共用脚本发布的 CSS 变量。

用户暗骰行动通常显示“暗骰未定”。AI 暗骰结果默认显示“暗骰已定”。“允许显示暗骰”默认关闭；开启后，行动面板可临时展开本轮暗骰难度，AI 消息中的暗骰数值与判定等级以可点击的遮罩呈现。每条遮罩独立揭开，结果发生变化后重新遮罩，关闭设置后重新隐藏。临时显示状态只保留在当前页面。

遮罩显示为 `[暗骰结果]`，揭开后显示 `暗骰·困难成功·17 / 50`。

“提前查看结果”默认关闭。开启后，已发送的玩家行动卡会显示结算骰点和分色判定。自定义行动按已掷出的骰点列出各可能结果的成功率区间。玩家暗骰结果需同时开启“允许显示暗骰”才会显示。

流式生成中的 AI 判定框固定为两行高度，溢出文字用省略号表示。生成结束或中止后，判定框按完整内容排版。

# 梦境创客 v0.2.2

## 移动端与界面

- 设置页顶部增加“返回会话”，可直接回到当前会话；收紧设置、消息与输入区的留白。
- 统一手机端菜单与弹层，改善短屏、软键盘和返回导航的使用体验。
- 修复 API 设置与 AI 思考期间的滚动问题，改进消息自动跟随和阅读位置恢复。
- 手机触屏使用 Enter 换行，点击发送按钮提交；改善输入法组合输入与提交后的草稿处理。
- 横幅统一迁移到通知中心：电脑右下角、手机顶部浮动显示，收起后可再次打开；需要处理的消息保留操作入口。

## 会话与配置

- 修复单页面使用时误报后端备份冲突、重试后提示持续存在的问题，并补充冲突处理入口。
- 改进 API 设置的编辑与保存，避免迟到的读取或保存结果覆盖新修改。
- Agent 配置和预设支持切页保留草稿、保存失败重试及放弃修改。
- 修复上下文超限恢复、手动压缩被拦截和摘要失败重试，改进 Token 估算与 API 用量回执的显示。
- 扩展 `/` 常用命令和 `@` 分类引用，提供统一的命令帮助与选择面板。
- 更新内置模型模板与匹配规则，补充 Gemini 4 Argon、GPT 6/6.1、Grok、Claude 5/5.5、Kimi K3.1 和 DeepSeek Flash 系列配置。

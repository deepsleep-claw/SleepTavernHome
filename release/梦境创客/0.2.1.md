# 梦境创客 测试版本 V0.2.1 更新

# 更新日志

## 新功能

* 新增 Gemini 原生接口支持，可以直接连接 Gemini，并从接口获取可用模型。
* 新增手动压缩会话功能，在输入框输入 `/压缩` 或 `/compact`，可以整理当前上下文后继续创作。
* 输入框新增 `@` 文件引用，可以搜索并选择工作区里的文件，方便告诉 AI 要查看或修改哪些内容。

## 使用体验优化

* 优化大文件的局部修改，AI 可以通过上下文定位，一次修改同一文件的多处内容，减少整篇重写。
* 优化补丁出错时的提示，更清楚地说明哪一处没有匹配，方便 AI 重新读取对应内容后继续修改。
* 优化长会话的自动压缩，保留最新要求和必要的工具执行过程，让压缩后的对话衔接更稳定。
* 优化自动保存和页面关闭后的恢复，减少频繁保存带来的开销，并显示当前是否还有内容等待保存。
* 更新 Gemini 和 DeepSeek 的模型配置，改善模型识别、思考参数和输出长度的适配。
* 优化资源读取失败时的提示，部分资源暂时不可用时仍可查看会话，并重新加载工作区。
* 补充世界书、文件修改和前端工程的创作参考资料，让 AI 更清楚地选择界面类型和正则作用范围。

## 问题修复

* 修复会话中断或仍在执行后续任务时，无法从已完成回复分叉的问题。
* 修复新建、克隆世界书时被误判为只读，导致操作失败的问题。
* 修复复制世界书失败后，可能影响后续搜索和文件操作的问题。
* 修复世界书条目删除后仍显示在列表中，以及新建条目后找不到实际文件的问题。
* 修复批量删除条目时，编号变化导致后续操作找不到目标的问题，并减少无关文件操作被连带跳过的情况。
* 修复前端工程只能生成普通 HTML 正则的问题，现在可以按工程配置生成酒馆助手交互界面。
* 修复编译后的正则无法配置为仅显示的问题，前端工程默认仅用于显示，避免整段界面代码进入 AI 提示词。
* 修复部分 User 重名、改名和设置头像时，目标识别不准确的问题。
* 修复部分读取或保存长时间没有返回时，任务难以及时停止的问题。

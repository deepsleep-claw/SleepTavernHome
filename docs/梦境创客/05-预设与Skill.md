# 预设与Skill

结构化预设只负责Agent的静态头部。你可以保存多套Profile，在设置中切换、新建、复制、导入或导出；导入导出格式为易于人工编辑的YAML。节点可以直接拖动排序、停用和删除；每个节点都有角色和正文，并可使用这些位置宏：

`{{agent_identity}}`、`{{tools_can_use}}`、`{{tool_rules}}`、`{{skill_instructions}}`、`{{safety_rules}}`、`{{output_style}}`、`{{custom_instructions}}`

这些宏都是可选插槽。`{{agent_identity}}`代表默认的Agent身份说明；如果希望完全自己编写身份，可以像内置默认预设一样，直接在“身份”节点写入正文而不使用这个宏。不会因为省略它而额外注入另一段身份。

未知宏或递归展开会拒绝保存。结构化预设本身只是可复用的静态头资源；真正决定新会话使用哪套预设的是“Agent配置”。工具Schema仍由AI SDK原生提供，顺序在会话内保持稳定。

每套Agent配置由一个结构化预设和一组Skill开关组成。你可以让同一个Skill在写作Agent中开启、在审阅Agent中关闭，而不必复制Skill文件。新会话采用当前Agent配置；已有会话继续使用创建时固定的组合，只有明确点击“保存并应用到当前会话”才会同时替换预设和Skill挂载。

Skill分为两类：

- `full`：正文自动进入静态头部。
- `on-demand`：只展示名称、摘要和路径，需要时由Agent读取 `SKILL.md`。

Skill是全局资源，不绑定某张角色卡或某个会话，可以跨角色复用。每个用户Skill对应酒馆文件存储中的一个稳定Markdown文件，保存时原地覆盖，不产生Revision碎片；设置只记录轻量索引。你可以直接在“设置 → Skill”新建、编辑、导入、导出和删除，在“设置 → Agent配置”为每套Agent分别开启或关闭它。导入总会生成新ID，不会静默覆盖已有Skill；修改或删除已有Skill会再次要求确认。

内置的“角色卡与世界书文件读写”Skill始终全量加载，不能修改或删除。当前用户Skill采用轻量单文件格式，只包含YAML Frontmatter和Markdown正文，不支持references、assets或脚本。Agent也可以通过当前会话挂载的
`/skills/` 提议修改；这类修改在工具执行前按审批模式保护，获准后立即写入同一个全局Skill库，并进入本轮操作日志。设置中锁定的Skill始终只读。

仓库中的内置内容以人类可直接编辑的源文件保存：`内置资源/Skills/角色卡工作区读写.md`使用YAML
Frontmatter加Markdown正文，`内置资源/预设/梦境创客默认预设.yaml`保存默认预设结构。TypeScript只负责读取和校验，不再维护第二份正文；文件格式错误会在自动测试或构建时直接报告。

已经运行的模型请求始终使用原来的Skill版本。当前会话已挂载Skill的正文更新从下一条用户消息开始采用；Agent配置开关的变化只影响新会话，除非用户明确把该配置应用到当前会话。Skill不会随着角色卡Undo/Redo一起回退。

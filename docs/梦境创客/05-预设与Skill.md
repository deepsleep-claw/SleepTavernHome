# 预设、Skill与Agent配置

结构化预设只负责Agent的提示词头部。你可以保存多套Profile，在预设设置中切换、新建、复制、导入或导出；节点支持排序、停用和删除，并可使用这些宏：

`{{agent_identity}}`、`{{tools_can_use}}`、`{{tool_rules}}`、`{{skill_instructions}}`、`{{safety_rules}}`、`{{output_style}}`、`{{custom_instructions}}`

宏是可选插槽。希望自己编写身份时可以完全省略 `{{agent_identity}}`。未知宏或递归展开会拒绝保存。工具Schema仍由AI SDK原生提供。

## Agent配置

Agent配置把“用哪套提示词、启用哪些Skill、开放哪些工具”组合成可复用方案。设置页分为三个页签：

- **主要**：配置名称与Agent预设。这里只把结构化预设显示为“Agent预设”，预设设置页的原有名称不变。
- **Skill**：逐个开启或关闭Skill，并覆盖为全量加载或按需加载。整组也可以一次开关。
- **工具**：逐个或整组决定Agent可以使用哪些工具。文件、世界书、聊天、工程预览和上下文压缩都可关闭；不做隐藏依赖补全。

内置Agent配置始终读取脚本内置源，不会被同名用户副本或旧缓存覆盖。它不可直接编辑，但可以“另存为”用户配置后修改。

每个会话独立记录所用Agent配置。会话工具栏可以显式切换；已有用户消息时会提醒这可能破坏模型缓存。配置修改会即时应用到使用它的空闲会话；正在运行的会话在本轮结束后采用新版本。工具和全量Skill发生变化时，下一次模型请求会使用新头部和新工具集合。

## Skill

Skill是全局资源，可跨角色、跨会话复用。Skill设置页保存它的默认加载策略；Agent配置可以为自己覆盖这个策略：

- `full`：正文进入提示词头部。
- `on-demand`：只展示名称、摘要和路径，需要时由Agent读取 `SKILL.md`。

无论哪种策略，Skill自身都可以关闭；关闭后既不会注入，也不会出现在Agent可探索的Skill索引中。“内置文件读写规则”负责解释当前VFS和酒馆映射，它也允许关闭，但关闭后Agent需要自行理解文件格式。

用户Skill可以在设置中创建、编辑、锁定、导入、导出和删除。导入总会生成新ID；锁定后Agent不能修改、移动或删除，完全权限模式也不能绕过。Agent通过 `/skills/user/` 创建或修改用户Skill时，操作同样进入本轮文件记录并参与Undo/Redo。

除内置文件读写规则外，较大的内置能力Skill在运行时按需从资源包下载，避免主脚本无限膨胀。首次加载会静默获取；失败后可到“资源下载”页手动重试，或在Agent配置中关闭对应Skill。资源不可用时不能启动依赖它的Agent请求。通过本地HTTP脚本加载开发版时，资源会优先从同一构建目录下载，方便离线调试。

远程内置Skill可以包含 `SKILL.md` 和自由组织的参考文件。导出Markdown时只导出主Skill；导出ZIP时包含完整资源。没有下载完成前不能查看、另存或导出。

## 生效时机

已经发出的模型请求不会在中途替换提示词或工具。空闲会话切换Agent配置后，下一次请求立即使用新配置；上下文压缩后也使用当前配置重新编译头部。按需Skill即使没有进入头部，只要在当前Agent配置中启用，Agent仍可从 `/skills/index.md` 发现并读取。

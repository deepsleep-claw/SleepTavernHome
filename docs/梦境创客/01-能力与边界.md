# 能力与边界

梦境创客可以编辑当前角色的文字信息、全部开场白、当前会话挂载的世界书，以及角色、当前预设和全局作用域的正则与酒馆助手脚本。它也能操作酒馆聊天，用真实预设生成回复来测试角色表现。全局会话还能列出、打开和关闭角色；角色会话不会获得角色导航工具。

它把这些内容组织成文件，让Agent使用熟悉的读取、搜索、写入、补丁、移动和删除方式工作。用户看到的是角色卡和世界书，Agent看到的是一棵安全的虚拟文件树。

首版有意保持克制：

- 角色会话一次绑定一张单角色卡；全局会话一次只挂载当前打开的单角色，不支持群聊和批量角色。
- 同一时间只运行一个Agent任务。
- 不使用Server Plugin、原生Extension、MCP或酒馆的 `generateRaw`。
- 不执行Skill脚本，也不访问Skill声明的网络资源；图片只作为附件或酒馆测试消息输入，不提供任意图片编辑能力。
- 后端只使用酒馆已有的设置与文件接口来保存数据，不承担Agent生成。
- 浏览器关闭后不会继续运行。

全局与当前预设中的正则、脚本仍会出现在工作区，方便Agent理解运行环境，但默认只读。确实需要维护它们时，可以显式开启始终标红的危险写入权限；它不再要求开发者模式。具体是否再次确认由手动审批、YOLO或完全权限模式决定。

每张角色卡都有稳定绑定。复制角色卡时，运行时会根据头像身份识别绑定碰撞，并为副本建立新的绑定；重命名不会让原会话失联。

测试聊天属于酒馆的真实聊天数据。切换聊天、改写楼层、生成Swipe与截断历史都会立即生效，也不会被文件Undo一并撤销。是否询问由当前全局审批模式和具体工具风险决定。

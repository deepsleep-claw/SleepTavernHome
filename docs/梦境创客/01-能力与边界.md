# 能力与边界

梦境创客可以编辑当前角色的文字信息、全部开场白、角色主世界书、附加世界书、聊天绑定世界书，以及角色自身的正则和酒馆助手脚本。它也能在一次明确授权后操作当前角色的酒馆聊天，用真实预设生成回复来测试角色表现。全局世界书默认只能阅读和搜索。

它把这些内容组织成文件，让Agent使用熟悉的读取、搜索、写入、补丁、移动和删除方式工作。用户看到的是角色卡和世界书，Agent看到的是一棵安全的虚拟文件树。

首版有意保持克制：

- 只支持当前打开的单角色卡，不支持群聊和批量角色。
- 同一时间只运行一个Agent任务。
- 不使用Server Plugin、原生Extension、MCP或酒馆的 `generateRaw`。
- 不执行Skill脚本，也不访问Skill声明的网络资源；图片只作为附件或酒馆测试消息输入，不提供任意图片编辑能力。
- 后端只使用酒馆已有的设置与文件接口来保存数据，不承担Agent生成。
- 浏览器关闭后不会继续运行。

全局与当前预设中的正则、脚本仍会出现在工作区，方便Agent理解角色所处的运行环境，但默认只读。确实需要维护它们时，可以在开发者模式下额外开启危险写入权限；Agent的每次写入仍需人工确认，不能由YOLO模式绕过。

每张角色卡都有稳定绑定。复制角色卡时，运行时会根据头像身份识别绑定碰撞，并为副本建立新的绑定；重命名不会让原会话失联。

测试聊天属于酒馆的真实聊天数据，不是角色卡候选稿。切换聊天、改写楼层、生成Swipe与截断历史都会立即生效，也不会被角色卡的Undo一并撤销。普通审批模式会在本轮第一次直接操作前说明这条边界并请求授权；YOLO模式则按你的选择直接执行。

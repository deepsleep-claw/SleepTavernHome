# 开发与自动测试

梦境创客源码位于 `src/酒馆助手/梦境创客/`。核心逻辑与酒馆接口之间有清晰边界，因此VFS、映射、事务、快照、Runner和大部分会话流程可以在项目内独立测试。

日常只需要两个新增命令：

```text
pnpm run test:agent
pnpm run check:agent
```

`check:agent`会执行Vitest、专用TypeScript检查和ESLint。正式 `pnpm run build` 也会包含它。测试使用Vitest、V8 Coverage和happy-dom；界面测试会真正挂载Vue组件。

正式构建后，可运行：

```text
node util/build_dream_card_agent_test_script.mjs
```

它会把本地 `dist/酒馆助手/梦境创客/index.js` 嵌入内部测试导入文件。这个文件不是正式发布包，也没有远程更新配置。

开发者模式会在界面中显示更多事件、会话版本与页面内存日志。运行中的工具事件和详细日志只在当前页面内存中更新；一轮结束后，会话恢复所需数据批量写入该会话唯一的压缩文件。诊断信息不应加入API Key、请求头值、创作正文或完整模型回复。

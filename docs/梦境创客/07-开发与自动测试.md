# 开发与自动测试

梦境创客源码位于 `src/酒馆助手/梦境创客/`。核心逻辑与酒馆接口之间有清晰边界，因此VFS、映射、实时写入、操作Undo/Redo、Runner和大部分会话流程可以在项目内独立测试。

日常只需要两个新增命令：

```text
pnpm run test:agent
pnpm run check:agent
```

`check:agent`会执行Vitest、专用TypeScript检查和ESLint。正式 `pnpm run build` 也会包含它。测试使用Vitest、V8 Coverage和happy-dom；界面测试会真正挂载Vue组件。正则、脚本映射、危险权限、敏感遮罩、玩家即时保存与Ace降级辅助逻辑都有独立用例。

正式构建后，可运行：

```text
node util/build_dream_card_agent_test_script.mjs
```

它会生成一个轻量的内部测试导入文件，通过
`http://127.0.0.1:5500/debug/dream-card-agent-local.js` 动态载入本地 `dist`，并走与正式版本相同的 `activate()`
入口。使用前先在仓库根目录启动带 CORS 的本地文件服务；每次重载都会附加缓存戳，因此无需把庞大的构建产物嵌入导入文件。

也可以直接把下面一行放进酒馆助手脚本：

```javascript
import 'http://127.0.0.1:5500/debug/dream-card-agent-local.js'
```

本地引导器会提供一个“已是最新版”的测试更新控制器，用于检查顶栏版本显示和更新设置页；它不会安装远程版本。

开发者模式会在界面中显示更多事件、会话版本与页面内存日志。运行中的工具事件和详细日志只在当前页面内存中更新；一轮结束后，会话恢复所需数据批量写入该会话唯一的压缩文件。诊断信息不应加入API Key、请求头值、创作正文或完整模型回复。

Ace不进入主Bundle。加载器固定主、备用CDN版本及SHA-384 SRI，并禁止Worker、自动补全和隐式无SRI模式加载。更新Ace版本时必须重新获取原始字节、更新全部完整性值，并验证两个CDN都失败时仍能用基础文本框保存。

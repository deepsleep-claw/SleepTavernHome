# API设置与常见错误

一套API Profile只包含名称、接口类型、Base URL、API Key、模型和自定义请求头。接口类型只决定请求协议，不代表某个默认服务商，也不会替你填写地址。

支持的协议是OpenAI Responses、OpenAI Chat、Anthropic Messages和OpenAI-compatible Chat。保存Profile不会发送连接测试；第一次真实创作请求才会验证配置。

Key与请求头对象会使用AES-GCM、随机盐和脚本内置固定密码保存。这能避免在酒馆设置中直接看到明文，但任何拿到脚本的人都能分析出固定密码，因此它只是可逆混淆，不是安全保险箱。建议只在本地酒馆中使用，并限制Key权限与额度。

常见问题：

- “请先打开一张角色卡”：当前没有单角色卡，或正在群聊。
- “请先保存并选择一套API设置”：还没有可用Profile。
- 浏览器无法访问接口：通常是CORS。请换用允许浏览器跨域访问的地址，或自行配置本地反向代理。
- 多个页面同时打开同一会话：梦境创客不使用后端租约，当前页面内存是运行中的唯一状态。请避免在两个页面同时编辑同一会话；固定名会话文件采用原子覆盖，最后一次完整保存会成为下次打开时看到的版本。
- 世界书只读：读取能力缺失或数据无法无损往返，梦境创客选择了安全降级。
- 全局或预设正则、脚本只读：先开启开发者模式，再到“常规”显式允许危险资源写入。关闭开发者模式会立即关闭入口和权限，但会记住原有选择，重新开启时恢复。
- `data.yaml`顶部出现黄色警告：本次敏感内容检测不可用，文件仍可正常读写，但Agent可能看到原文；请暂时避免让它处理密钥。
- 增强编辑器不可用：固定版本的主、备用CDN都被网络或页面策略拦截；界面会自动使用基础文本框，无需重新加载会话。
- 上下文已满：新建会话、编辑旧消息，或换用更大的上下文模型。

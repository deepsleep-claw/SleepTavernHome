# 对话怎样运行

酒馆普通聊天和梦境创客是两条独立生成链。梦境创客使用Vercel AI SDK Core请求你选择的接口，酒馆继续使用原来的预设与生成系统，两者可以同时存在。

一次创作大致会经历这些状态：

1. 发送要求时，先保存角色卡与世界书的执行前检查点。
2. Agent在隔离的Working Copy里读取和修改文件。
3. 每个成功工具步骤立即记入会话日志。
4. Agent完成或被主动停止后，Working Copy被冻结成候选版本。
5. 普通模式等待逐项批准；YOLO模式自动采用低风险且无冲突的修改。
6. 最终只向酒馆写入真正变化且被批准的路径。

输入和中途引导共用同一个输入框。Agent空闲时，右下角箭头发送普通消息；运行后同一个箭头会发送中途引导。引导会被标记为旧目标的补充，并在下一次工具结果后加入；如果这一轮已经直接结束，则作为下一条消息发送。

空闲时可以用输入框左下角的按钮添加普通文件或图片，也可以把文件拖进输入框，或直接按Ctrl+V粘贴剪贴板中的图片。附件会先显示在输入框上方，发送前可以逐项移除。单项默认不超过20MB，每条消息最多10项且总计不超过50MB；明确标记为不支持视觉的API Profile不能发送图片。运行中的中途引导暂不接受新附件。

Agent运行时仍可以切换到其它已经打开的会话页签，原任务会在当前页面后台继续。运行中的页签会显示状态点并暂时禁止关闭，任务结束后恢复普通关闭行为。

你和Agent的消息都支持Markdown。标题、列表、表格、引用、粗体、链接与代码会按排版显示；使用`![说明](图片地址)`可以插入图片，单独占一行的常见图片链接也会自动显示为图片。链接会在新标签页打开，消息中的危险HTML会被过滤。

上下文达到约70%时，Agent会先调用压缩工具，再继续原任务。界面会展示系统、用户、助手和工具各自的估算占用。全部用户消息本身达到80%时会暂停，提醒你新建会话、编辑历史或换用更大窗口的模型。

# 对话怎样运行

酒馆普通聊天和梦境创客是两条独立生成链。梦境创客使用Vercel AI SDK Core请求你选择的接口，酒馆继续使用原来的预设与生成系统；Agent需要测试角色时，也可以明确调用酒馆自己的生成能力。

一次创作大致这样进行：

1. 用户发送要求，梦境创客建立这一轮的文件操作记录。
2. 读取工具直接查看酒馆此刻的文件投影。
3. 写入工具在执行前按当前全局审批模式决定是否询问。
4. 获准的工具立即修改真实资源；成功、失败和实际变更都返回给Agent。
5. Agent可以根据失败信息重新读取、改用Patch或调整计划，不会因为普通工具失败自动结束整轮。
6. 本轮结束后，时间线显示一张只用于查看和Undo/Redo的Diff卡片。

审批有三档：手动审批只自动放行只读工具；YOLO自动放行普通写入，高风险操作仍询问；完全权限直接放行所有工具，开启时会明确警告。拒绝某次工具不会结束Agent，模型会收到拒绝结果并自行决定下一步。

输入和中途引导共用一个输入框。Agent空闲时发送普通消息；运行后同一个按钮发送中途引导。引导会标为旧目标的补充，在下一次工具结果后加入；如果这一轮已经结束，就作为下一条消息发送。

空闲时可以添加普通文件或图片，也可以拖入文件或按Ctrl+V粘贴图片。附件原件保存在当前角色共享的 `/files/`，会话只保存引用。大于1MB的常见图片在发送给模型时默认生成不改变宽高的低损WebP临时副本，原图不会被改写。

全局只允许一个Agent任务运行。你仍可切换其它页签；运行页签的关闭按钮会变成停止按钮，确认后同时停止任务并关闭页签。若工具正在调用酒馆生成，停止也会停止那次酒馆生成，并把“用户打断”作为工具结果交给Agent状态机。

你和Agent的消息都支持安全的GFM Markdown，包括标题、列表、表格、引用、代码、链接和图片。上下文达到约70%时会先压缩再继续；界面会同时显示API返回的Token用量和本地估算信息。

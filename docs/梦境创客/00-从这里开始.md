# 梦境创客：从这里开始

梦境创客是运行在酒馆页面里的角色卡创作助手。它有自己的对话、文件工作区和API设置，不会挤占酒馆的普通角色聊天。

第一次使用时：

1. 在酒馆里打开一张单角色卡。
2. 点击默认位于右侧中部的“梦”悬浮按钮，或从魔法棒菜单进入。悬浮按钮可以自由拖到任意位置；九宫格区域只决定它之后参照左边、中心或右边以及上方、中部或下方。旋转屏幕或调整窗口时，它会按这个相对锚点移动，而不会跳到九个固定位置。
3. 在“API”页保存一套接口设置。Base URL和模型都由你填写；保存时不会发送测试请求。
4. 在“Agent配置”页选择一套结构化预设，并开启这套Agent需要使用的Skill。
5. 回到“会话”页，新建一个创作会话。
6. 说出你想完善的内容，检查Diff，再决定哪些修改写回角色卡。

第一次发送要求后，会话会自动使用输入的前10个字命名，也可以随时点击会话标题旁的铅笔重新命名。

关闭浮窗不会停止正在运行的Agent。Agent运行时的步骤和快照只保存在当前页面，整轮结束、停止、失败或进入审批后才批量保存。关闭整个浏览器页面会丢弃尚未结束的这一轮；此前已经完整保存的会话不受影响。

同一浏览器里同时打开多个酒馆页面时，会话索引和轻量设置会实时同步。每次保存都会把本页真正改变的部分合并到最新版本，不会用旧页面的完整副本覆盖另一个页面刚创建的会话。

# 梦境创客：从这里开始

梦境创客是运行在酒馆页面里的角色卡创作助手。它有自己的对话、文件工作区和API设置，不会挤占酒馆的普通角色聊天。

第一次使用时：

1. 点击默认位于右侧中部的“梦”悬浮按钮，或从魔法棒菜单进入。悬浮按钮可以自由拖到任意位置；九宫格区域只决定它之后参照左边、中心或右边以及上方、中部或下方。旋转屏幕或调整窗口时，它会按这个相对锚点移动，而不会跳到九个固定位置。
2. 新建会话时选择“角色会话”或“全局会话”。角色会话需要选择一张酒馆角色卡；全局会话不要求预先打开角色，并能在运行中使用角色导航工具。
3. 在“API”页保存一套接口设置。Base URL和模型都由你填写；保存时不会发送测试请求。
4. 在“Agent配置”页的“主要、Skill、工具”三个页签中选择预设、启用知识和开放能力。
5. 回到会话，说出你想完成的工作。写工具会按全局审批模式即时执行，完成后可在Diff中审阅并按轮Undo/Redo。

第一次发送要求后，会话会自动使用输入的前10个字命名，也可以随时点击会话标题旁的铅笔重新命名。

关闭浮窗不会停止正在运行的Agent。文件工具获准后会立即作用于酒馆；会话记录在整轮结束、停止或失败后批量保存，临时断线时还会留下浏览器待同步副本。关闭整个浏览器页面不会让Agent继续后台运行。

同一浏览器里同时打开多个酒馆页面时，会话索引和轻量设置会实时同步。每次保存都会把本页真正改变的部分合并到最新版本，不会用旧页面的完整副本覆盖另一个页面刚创建的会话。

# 梦境创客：从这里开始

梦境创客是运行在酒馆页面里的角色卡创作助手。它有自己的对话、文件工作区和API设置，不会挤占酒馆的普通角色聊天。

第一次使用时：

1. 在酒馆里打开一张单角色卡。
2. 点击右下角的“梦”悬浮按钮，或从魔法棒菜单进入。
3. 在“API”页保存一套接口设置。Base URL和模型都由你填写；保存时不会发送测试请求。
4. 回到“会话”页，新建一个创作会话。
5. 说出你想完善的内容，检查Diff，再决定哪些修改写回角色卡。

关闭浮窗不会停止正在运行的Agent。关闭整个浏览器页面则会中断任务；重新打开时，梦境创客会从最后一个成功步骤恢复。

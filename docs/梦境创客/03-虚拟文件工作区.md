# 虚拟文件工作区

“文件”页展示当前会话的Card Workspace。常用位置如下：

- `/character/`：角色描述、性格、场景、示例对话等固定文件。
- `/greetings/`：具名开场白；`index.yaml`决定显示顺序。
- `/worldbooks/`：可编辑世界书与绑定关系。
- `/worldbooks-global-readonly/`：全局或无法安全往返的只读世界书。
- `/library/worldbooks/`：本会话按需挂载的只读参考世界书。
- `/context/chats/`：按酒馆聊天分目录、再按百层分页的测试聊天投影。
- `/skills/`：挂载到当前会话的全局Skill版本；它方便Agent读取和提议修改，但不属于角色卡数据。
- `/regexes/`：角色、全局与当前预设中的酒馆正则，每条规则对应一个YAML文件。
- `/tavern-helper-scripts/`：角色、全局与当前预设中的酒馆助手脚本。
- `/files/`：当前角色的持久共享文件。所有该角色会话都能看到，附件原件也保存在这里；修改会进入操作记录与Diff。
- `/temp/`：只属于当前会话的临时文件与图片压缩缓存，不参与Undo/Redo，清理缓存后可以按需重新生成。

现代预设通常会关闭角色卡中 `description.md`、`personality.md`、`scenario.md` 与 `example-dialogue.md` 的传统注入，因此内置Skill把它们标为低优先级：旧卡已有内容时应先读取并尊重，但新设定通常更适合放进世界书。角色名、头像和绑定标识始终只读。

世界书条目的正文使用Markdown，设置放在文件开头的YAML
Frontmatter中。正则关键字会明确记录类型、表达式和值，避免普通字符串与正则混淆。酒馆暂时不认识的字段会原样保留；如果某本世界书无法可靠读取，它会自动降级为只读。

世界书名称先通过搜索工具确认。Agent可以新建空世界书、完整复制现有世界书作为新版本、调整角色或聊天绑定，也可以只把某本未绑定世界书挂到 `/library/worldbooks/` 参考。发现并绑定酒馆中已有的世界书不会被误判为新建同名资源。

`/context/chats/index.yaml`记录会话开始时的聊天、当前活动聊天和已挂载的短ID。每个 `cXX` 目录是一份真实酒馆聊天，楼层文件从0开始；只有活动聊天可写。修改正文、角色、名称或隐藏状态可以使用普通文件写入与Patch，直接追加下一楼也可以写新文件。删除必须使用截断工具，因为酒馆的语义是“从这一楼起全部删除”；Swipe也只允许操作最新的助手楼层。

正则文件会保留酒馆原始字段，`substituteRegex`会明确显示为 `none`、`raw` 或 `escaped`，不需要Agent猜测空值语义。每个脚本使用独立目录，其中 `info.yaml`保存名称、启用状态等短信息，`info.md`保存可能很长的说明，`script.js`保存代码，`data.yaml`保存数据；父目录的 `tree.yaml`维护顺序。新建脚本时先写 `info.yaml`，随后再补其它文件。

路径采用大小写敏感的POSIX规则，不能使用 `..` 越过根目录。搜索工具的体验接近
`rg`：正文默认按普通文本查找，只有明确选择正则模式时才解释正则；`glob`与`excludeGlob`只负责筛选文件路径。它还支持多组Glob、大小写、完整单词、独立的前后文行数和结果上限。这样搜索
`*`、`[name]` 等普通符号时不会误触发正则错误。

一次工具错误会作为带有错误代码、消息和相关路径的结果交还给Agent。Agent可以据此修正参数后重试、改用其他工具或向你说明，而不会因为可恢复的文件操作错误自动终止整轮对话。模型请求、上下文耗尽或页面运行环境等无法继续的问题仍会正常暂停。

Agent只会看到 `/files/` 和 `/temp/` 这两个虚拟入口，不会看到酒馆中的物理文件名、下载地址、角色绑定ID或会话ID。文本文件照常使用读写和Patch工具；图片等二进制文件由 `read_file` 作为多模态内容交给模型，不能使用文本Patch。

`read_file`返回带行号的读取视图，形如 `12 | 正文`。左侧行号只是帮助Agent定位的元数据，不属于文件内容，也不能复制进写入或Patch。读取默认最多1000行和100000字符；大文件会返回总行数和下一段的起始位置，Agent可以继续分段读取。

文件编辑器会按Markdown、YAML、JSON与JavaScript提供行号、搜索、折叠和撤销。增强编辑器从带完整性校验的固定CDN版本按需加载；主、备用CDN都不可用时会自动退回基础文本框，不影响查看与保存。Markdown可以切换安全预览，超过1MB的正文只在明确点击后渲染。

脚本的 `data.yaml`可能包含密钥。界面始终显示真实内容，但会用盾牌和范围标记提醒；Agent读取时才替换成不可伪造的占位符，写回时再恢复未改动的原值。检测器临时失败会在文件顶部警告并按原文继续，不会把保护机制误当成核心写入能力。

Agent运行和等待工具确认期间编辑器只读；完成、停止或失败后可以手动保存。玩家保存会立即写入酒馆，不进入Agent审批；系统会记录对应文件操作，并在会话中合并显示一张“玩家修改工作区”卡片。Agent会在后续上下文中看到这些变化，但 `data.yaml`中的敏感值仍会被遮罩。

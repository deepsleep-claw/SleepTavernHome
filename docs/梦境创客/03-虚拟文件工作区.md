# 虚拟文件工作区

“文件”页展示当前会话的Card Workspace。常用位置如下：

- `/character/`：角色描述、性格、场景、示例对话等固定文件。
- `/greetings/`：具名开场白；`index.yaml`决定显示顺序。
- `/worldbooks/`：可编辑世界书与绑定关系。
- `/worldbooks-global-readonly/`：全局或无法安全往返的只读世界书。
- `/context/chat/`：分页的只读聊天历史。
- `/skills/`：Skill索引、内置Skill和用户Skill。

世界书条目的正文使用Markdown，设置放在文件开头的YAML Frontmatter中。正则关键字会明确记录类型、表达式和值，避免普通字符串与正则混淆。酒馆暂时不认识的字段会原样保留；如果某本世界书无法可靠读取，它会自动降级为只读。

路径采用大小写敏感的POSIX规则，不能使用 `..` 越过根目录。搜索工具支持正则、固定字符串、Glob、大小写、上下文行和结果上限，使用感受接近 `rg`。

Agent运行时编辑器只读；暂停、完成或等待最终审批时可以手动编辑Working Copy。手动保存也会进入同一套快照、Diff和审批保护。

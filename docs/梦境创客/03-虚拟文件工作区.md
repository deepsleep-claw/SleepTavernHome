# 虚拟文件工作区

梦境创客把酒馆里的角色卡、世界书、正则、脚本和会话文件整理成一棵统一文件树。Agent使用普通的列出、读取、写入、Patch、移动、删除与搜索工具工作，不需要记忆酒馆内部的数据结构。

## 当前目录

```text
/
├─ identity.yaml                 当前环境与已打开角色的只读身份
├─ character/                   仅在打开角色后出现
│  ├─ definition/               角色文本字段
│  ├─ greetings/                具名、有序开场白
│  ├─ chats/                    已挂载的酒馆聊天
│  ├─ files/                    该角色跨会话复用的文件
│  └─ temp/                     当前会话的角色临时文件
├─ worldbooks/                  当前会话挂载的可写世界书
├─ regexes/
│  ├─ character/                当前角色正则
│  ├─ preset-current/           当前预设正则
│  └─ global/                   全局正则
├─ scripts/
│  ├─ character/                当前角色酒馆助手脚本
│  ├─ preset-current/           当前预设脚本
│  └─ global/                   全局脚本
├─ files/                       全局持久文件
├─ temp/                        当前会话全局临时文件
├─ skills/                      当前Agent启用的Skill
└─ context/
   └─ environment.md            全局/角色环境与动态挂载说明
```

全局会话可以在没有打开角色卡时使用。角色会话始终绑定一张角色卡；全局会话则可通过专用工具打开或关闭角色。角色被打开时，它绑定和附加的世界书会自动挂载到 `/worldbooks/`；关闭角色时这些世界书会全部卸载。手动搜索并挂载的世界书也在同一目录中，并且只要能够无损往返就可以读写。

## 文件与目录操作

`list_path`既可以查看单个文件信息，也可以像 `ls` 或 `tree` 一样列出目录。它支持递归、最大深度、Glob与文件类型筛选，并返回文件大小和目录直接子项数量；为避免一次塞满上下文，单次最多返回2000项、递归深度最多10层。

路径采用大小写敏感的POSIX规则，不能使用 `..` 越过根目录。`search_files`的体验接近 `rg`：正文默认按普通文本查找，只有明确选择正则模式时才解释正则；Glob只筛选路径。一次可恢复的工具错误会作为结构化结果交回Agent，由Agent重读、修正参数或改用其他工具，不会自动中断整轮。

`read_file`返回带行号的读取视图，例如 `12 | 正文`。行号只是定位信息，不属于文件内容。读取默认最多1000行和100000字符；大文件会返回总行数与下一段起始位置。

`write_file`用于创建新文件；覆盖已有文件必须显式声明。`apply_patch`使用模型训练中常见的统一Diff语义：它会先读取真实文件，再应用Patch并写回。Agent的每次文件操作都会即时作用于真实资源，失败结果会立即返回；不会等到整轮结束后再整体提交。

## 角色与聊天

现代预设通常不会注入 `description.md`、`personality.md`、`scenario.md` 与 `example-dialogue.md`，因此内置文件读写规则把它们标为低优先级：旧卡已有内容时先读取和尊重，新设定通常更适合写入世界书。角色名、头像和绑定标识始终只读。

`/character/chats/index.yaml`记录会话开始时的聊天、当前活动聊天和已挂载短ID。每个 `cXX` 目录是一份真实酒馆聊天，楼层从0开始；只有活动聊天可写。正文、角色、名称与隐藏状态可以用普通文件写入或Patch，追加下一楼也可以新建文件。删除必须使用聊天管理工具的截断动作，因为酒馆的语义是“从指定楼层起全部删除”；Swipe和继续生成只允许操作最新助手楼层。

## 世界书、正则与脚本

世界书条目正文使用Markdown，设置放在YAML Frontmatter中。正则关键字会明确记录类型、表达式和值。酒馆暂时不认识的字段会原样保留；无法无损往返的世界书会降级为只读。Agent可以搜索、新建、复制、挂载、卸载世界书，也可以调整当前角色或聊天的绑定。

正则文件保留酒馆原始字段，`substituteRegex`明确显示为 `none`、`raw` 或 `escaped`。每个脚本使用独立目录：`info.yaml`保存名称和启用状态等短信息，`info.md`保存长说明，`script.js`保存代码，`data.yaml`保存数据；父目录的 `tree.yaml`维护顺序。

`regexes/preset-current`、`regexes/global`以及对应脚本目录属于高风险范围。允许修改非角色正则与脚本的开关会一直标红；手动审批模式逐次确认，YOLO模式也会按既定高危规则确认，完全权限模式才全部放行。

## 工程、Skill与普通文件

HTML工程不再占用特殊目录。Agent可以在 `/files/` 或 `/character/files/` 中自由创建目录，存在 `project.yaml`时界面会把它识别为工程，并提供检查、编译、预览和导出入口。源码与编译到酒馆正则的产物没有持续绑定关系；每次编译都是显式操作。

`/skills/`展示当前Agent配置启用的Skill。每个Skill可由Agent配置单独关闭，并可覆盖为全量加载或按需加载；Skill设置页中的策略只是默认值。按需Skill的摘要始终可见，正文需要Agent读取 `SKILL.md`。内置文件读写规则也可以关闭，但关闭后Agent不会获得这套VFS的完整写作说明。

`/files/`在所有全局会话间复用，`/character/files/`在同一角色的会话间复用；两个 `temp` 目录只服务当前会话。附件原件保存在对应角色的持久文件中。Agent只看到虚拟路径，不会看到酒馆的物理文件名、下载地址、绑定ID或会话ID。

## 编辑、安全与历史

文本编辑器按Markdown、YAML、JSON与JavaScript提供行号、搜索、折叠和撤销。Markdown可切换安全预览；增强编辑器加载失败时会自动退回基础文本框。

脚本 `data.yaml`可能包含密钥。界面始终向玩家显示真实内容；Agent读取时才用不可伪造占位符遮罩疑似敏感值，写回时恢复未改动的原值。保护检测失败会警告并按原文继续，不把辅助保护当成核心写入能力。

每轮有文件变化时，时间线会显示文件与增删行数，并可跳转到Diff审阅。Undo/Redo记录的是实际发生的创建、删除、移动和Patch操作，而不是整份快照；无法安全撤销的项会先模拟并让玩家决定取消或跳过冲突项。酒馆聊天生成、截断和Swipe不参与Undo/Redo。
